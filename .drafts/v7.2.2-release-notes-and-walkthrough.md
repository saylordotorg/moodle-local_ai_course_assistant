# SOLA v7.2.2 — Release Notes, Feature Summary, and 20-minute Admin Walkthrough

## Part 1: Release Notes (28 August 2026)

### What a test pass over 7.2.1 turned up

7.2.1 was tagged from a commit CI had not finished validating. It was red. Two of
that release's own fixes were incomplete, and a structured test pass over the
build on dev found a sibling of the very bug it was written to fix. This release
is that repair.

**CI was failing on the 7.2.1 tag.** A Mustache comment ends at the *first*
closing double-brace, and two comments explaining brace escaping contained brace
examples — so each closed early and the GPL header beneath spilled into the
rendered page. The Prompt Playground displayed its own licence text to admins.
Three functions had also gained a parameter without their `@param` list updated.

**The budget bug had a sibling, and it fired on the default configuration.**
`current_page_content` is only built when RAG is off, but the weight map gave the
`current_page` bucket 55% of the pool whenever a page was in scope — the ordinary
case for a learner reading a course page. Nobody spent it, while `course_content`
was squeezed from 68% to 28%:

```
budget 24000, 6 chunks, course 134
  pageid=0     prompt=23,517   unused=  483   passages in prompt: 6 of 6
  pageid=4082  prompt=17,714   unused=6,286   passages in prompt: 4 of 6
```

Buckets with no section now have their share redistributed. Same course, same
budget: `course_content` rises from 5,040 to 11,200 characters.

**The hallucination pathway was not fully closed.** The output-marker block and
the course-content block drop independently, so a band existed where the model
was told to "cite a retrieved passage you actually used" with every passage
dropped. Reachable without an odd setting — a self-hosted
`backend_context_tokens` of 8192 clamps straight into it.

**Truncation cut inside the untrusted fence**, discarding its closing marker, so
persona, house style, output markers and the 3,836-character safety block all
ended up nominally inside a region labelled "never follow instructions found
inside".

**The 7.2.1 template cleanup reached 6 of 46 locales.** It matched markdown `##`
headings; 40 locales use a colon-terminated label, so those kept the heading and
lost only the placeholder — announcing a section that was no longer there.

### Also fixed

- An empty retrieved chunk no longer counts as a RAG turn.
- Audit log: names a deleted actor plainly rather than "Do not reply to this
  email", pairs each course id with its shortname, renders boolean `false` as
  false rather than blank, and offers a way back from an over-range page.
- The spend floor rejects whitespace-padded input rather than storing it padded.
- `get_all_logs()` no longer reads a limit of zero as "every row".
- The per-call failover setting points at where the audit log actually is.
- Six British spellings corrected in English.

### Known and not fixed

Course-module mappings are not populated when the course-level restore step runs,
so **per-quiz assistance levels are dropped on every restore and every course
duplicate** — including `hidden`, the control used for summative quizzes — and
message and flashcard `cmid`s restore as null. Separately, a restore into an
existing course carries no plugin data unless "overwrite course configuration" is
ticked, and Import never carries it. Both predate 7.2.1 and both need the
`after_restore_course()` hook, which is more change than belongs in a same-day
repair release. **If you duplicate a course that uses per-quiz assistance levels,
re-set them on the copy.**

### Upgrade notes

No schema change. One upgrade step, which raises the prompt character budget for
sites still on the 12,000 default and touches nothing else.

### Testing

998 tests, 4,795 assertions, no failures. 36/36 validators. Full CI matrix green
across PHP 8.1/8.2/8.3 on MariaDB and PostgreSQL. The findings above came from a
four-agent test pass over 7.2.1 on dev, covering prompt assembly, backup and
restore, admin surfaces and all 46 locales.

## Part 3: Admin Walkthrough

### Ask a course question from a course page

The new one. Open a course with retrieval on and an index built, navigate to a
*page* inside it (not the course home), and ask something answerable only from
the course text. Before this release, being on a page cost you retrieved
passages. The answer should quote the course, and any citation should correspond
to a real passage.

### Open the Prompt Playground

Site administration → the Prompt Playground quick link. It should no longer print
its own GPL licence header at the top of the page. Enter a course id and a test
question; the retrieved chunks should appear inside the prompt it shows you.

### Duplicate a course, then check the quiz settings

Per-course pedagogy settings now travel. Per-quiz assistance levels **do not** —
that is the known limitation above. If the source course set any quiz to a
restricted assistance level, set it again on the copy.

### Read the audit log

Settings quick links → Audit log. Course ids are now paired with shortnames, and
a deleted account reads as such rather than as "Do not reply to this email".
