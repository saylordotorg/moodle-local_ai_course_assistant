# SOLA v7.8.4: Release Notes and Walkthrough

## Part 1: Release Notes (9 October 2026)

## v7.8.4 (9 October 2026): a reloaded answer keeps its source link (#310)

A grounded answer shows "From: Understanding Economic Systems" while it streams. Reload the page and the same answer, now drawn from history, had no source link, so it looked ungrounded. The cause: the saved copy has every protocol marker removed, including the source marker, and the table had no column for it.

Each assistant message now stores which source pill it showed (`page`, `course`, `general` or `activity:ID`) in a new nullable column, taken from the raw reply before the markers are removed. When history loads, the server resolves the link for the learner reading it: an activity that was deleted or has since been hidden from them links to the course and its name is not returned. Course backup and restore carry the field. Answers saved before 7.8.4 have no source and show no link, as before. The upgrade adds one nullable column.

## Part 2: Walkthrough (about 2 minutes)

1. Ask a question that SOLA answers from a course page. Note the "From: ..." link under the answer.
2. Reload the page and reopen SOLA. The same link is under the reloaded answer, and clicking it opens the activity.
3. Hide that activity from students and reload as a student: the link goes to the course and the activity name is gone.
