# SOLA v7.6.9: Release Notes

## Part 1: Release Notes (4 October 2026)

## v7.6.9 (4 October 2026): the last two pages move to templates, and two bugs they were hiding

**The plugin-directory review's template work is finished.** It named eight
places that built pages by echoing HTML with inline scripts, inline styles or
an inline click handler. Six were converted in v7.6.3. This release converts
the last two: the Python sandbox page, and the "reset to template" button on
the system prompt setting. A test now covers all eight, so the pattern can't
quietly come back.

**The sandbox never showed a learner their actual Python error.** When code
failed, the learner saw only the word "PythonError". The sandbox captures
Python's error output so it can display it, and that same capture is where the
runtime puts the error message. The page then read the message from the wrong
place, which was always empty. This has been true for as long as the sandbox
has existed. It was found by running the converted page in a real browser, and
learners now see the full error, ending with the line that names what went
wrong.

**The sandbox also says sooner when its runtime can't load.** The old page
checked for up to 15 seconds whether the Python runtime had arrived. The page
now gets a direct answer from the browser, so a wrong runtime address shows an
error within a couple of seconds.

**"Reset to template" garbled the default prompt in 37 of 46 languages.** The
button restored the default system prompt using a browser function that
doesn't handle accented or non-Latin characters, so a French prompt came back
as "Vous Ãªtes... le rÃ´le de l'Ã©tudiant" instead of "Vous êtes... le rôle de
l'étudiant". English uses only plain characters, so it was never noticed. The
default prompt now reaches the button exactly as written, and the button only
loads on the page that shows it.

**The Marketplace description is now checked against what the plugin
declares.** The review found the listing promising support through Moodle 5.3
while the plugin declares 4.5 to 5.2. The README was already checked against
the plugin's declared versions; the listing description, which is what gets
pasted onto moodle.org, wasn't. It now is. The listing text on moodle.org itself
still has to be updated by hand.

## Part 3: Admin Walkthrough

Unchanged from v7.5.7, with one addition: after upgrading, check Site administration, Plugins, Local plugins, AI Course Assistant, and confirm "Remote config URL" is empty.
