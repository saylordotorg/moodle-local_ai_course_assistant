# SOLA v7.6.8: Release Notes

## Part 1: Release Notes (4 October 2026)

## v7.6.8 (4 October 2026): a mistyped retry setting can no longer tie up the server for hours

**One wrong number in the retry settings could freeze part of the server.**
When an AI provider is busy it asks the plugin to wait and try again. Two
settings control that: how many times to retry, and the longest wait to accept.
The retry count had a minimum but no maximum. If it were mistyped as 20000 and
a provider were busy, which is exactly when the setting matters, a single
request would sit waiting for about 17 hours. That wait doesn't count as running
time, so PHP's time limit never stopped it, and the server process it held could
serve nobody else. A few learners hitting a busy provider at once could use up
every process the site has. The longest-wait setting had the same gap: it only
capped a wait the provider asked for, so a large value let a misbehaving
provider request a wait of hours.

**Fixed in three layers, because each catches something the others miss.**

- The settings page now refuses a value outside the allowed range, 0 to 10
  retries and 0 to 60 seconds, and says what the range is, instead of saving a
  number the plugin then ignores.
- A value that never went through that page, because it was saved before this
  release, forced in the site config, or set by an upgrade or the command line,
  is brought back into range whenever it's read.
- The total time one request may spend waiting is capped at 30 seconds. Even
  the highest allowed settings, 10 retries of 60 seconds each, would otherwise
  hold a process for ten minutes.

The chat and embedding paths used to each read and half-check these settings in
their own copy of the code. Both now take them from one shared place, so the
limits can't drift apart.

**If your site already has an out-of-range value**, it is safe from this
release onward, because the plugin brings it into range when reading it. The
settings page will flag it the next time that page is saved, so you can choose
a value deliberately.

## Part 3: Admin Walkthrough

Unchanged from v7.5.7, with one addition: after upgrading, check Site administration, Plugins, Local plugins, AI Course Assistant, and confirm "Remote config URL" is empty. If your site had never set it, the upgrade has cleared it and remote configuration is now off. If you had set your own URL, it is untouched and still active.
