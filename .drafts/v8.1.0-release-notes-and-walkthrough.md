# SOLA v8.1.0: Release Notes, Feature Summary, and Admin Walkthrough

## Part 1: Release Notes (21 November 2026)

## v8.1.0 (21 November 2026): Gemini text to speech, and voice models that keep up with shutdowns

**Why this release exists.** Google is shutting down gemini-3.1-flash-tts-preview, gemini-2.5-flash-preview-tts and gemini-2.5-pro-preview-tts on 18 December 2026, and gemini-2.5-flash-native-audio-preview-12-2025 on 31 March 2027. SOLA had no Gemini voice at all, and its OpenAI and xAI voice models were literals in the code, so the next retirement of any voice model would have broken speech until someone shipped a release. This release adds Gemini text to speech and one catalog of voice models with shutdown dates and successors, read at call time.

**The voice model catalog.** `classes/voice_model_catalog.php` lists, per provider and capability (text to speech, Realtime or Live, speech to text), a default model and every known model with its status, shutdown date (UTC) and successor. Each voice call asks it which model to send: a blank choice means the default, a model it doesn't know is sent as typed, and a model past its shutdown date is replaced by its declared successor, following the chain. It never moves to a model that isn't in the catalog. The Gemini entries come from Google's notice as relayed by the site owner and weren't independently verified; they are data in one place, so a wrong ID or date is a one-line fix.

**Gemini text to speech.** The Voice providers table accepts `gemini` rows (text to speech only; the Realtime and speech-to-text choices don't offer them) and every row gains an optional **TTS model** column. tts.php calls Gemini's `generateContent` with the key in the `x-goog-api-key` header, asks for audio with a prebuilt voice (default Kore), and wraps the returned PCM (16-bit, 24 kHz, mono) in a WAV header so the browser plays it with no JavaScript change. A voice name from another provider, remembered by the browser, is replaced by the row's voice. Rows saved before this release are stored and behave exactly as before.

**If a provider refuses a model.** When the provider answers that the configured model doesn't exist (HTTP 404, or a 400 that says so), tts.php retries once on the catalog successor (or, for a model the catalog doesn't know, the default), writes a `voice_model_fallback` audit row and emails the spend alert recipients once for that model.

**Warnings ahead of time.** A daily task, **Warn about voice models that are being retired** (03:55), emails the spend alert recipients about voice models in use whose shutdown is 45 days away or less, and about catalog models, in use or next in line, that the provider's model list no longer shows. It reads the same Gemini and OpenAI model lists the model upgrade discovery reads, with keys only in headers, and it never changes a setting. Each finding is emailed once.

**Spend.** Gemini speech is recorded as `gemini_tts` in the voice spend bucket, the spend dashboards and token analytics, with Gemini's own token counts. **No Gemini TTS price is in the repo**, so these rows are unpriced: they show in the model registry's unpriced-models banner and the daily price-drift check, not as free. One exception: `gemini-2.5-flash-preview-tts` matches the `gemini-2.5-flash` chat price prefix and is priced as chat text, which is wrong for audio. Add a model registry row with Google's audio price before relying on the spend caps for Gemini speech.

**Upgrade notes.** No schema change and no upgrade step; Moodle registers the new task on upgrade. No JavaScript changed. Two admin strings changed meaning (the voice provider list and its error) and fall back to English until translated, along with the 11 new admin strings.

### Not verified

- No live call to Google was made. The request and response shape follow Google's Gemini 2.5 TTS documentation; the 3.8 model IDs, the voice list for 3.8, and whether 3.8 TTS keeps the same shape are unverified. Live check: add a Gemini voice row on a dev site with a test key, set it as the text to speech provider, press a speaker button, and confirm tts.php returns 200 with `type: audio/wav` and the audio plays; then set the TTS model to `gemini-0-tts` and confirm one `voice_model_fallback` audit row and one email; then run the `voice_model_watch` task from the CLI and read its output.
- Gemini TTS prices (see Spend).

### Testing

## Part 2: Key SOLA Features

What the plugin does as of v8.1.0, for an admin deciding what to switch on.

- **A tutor that knows the course.** Answers come from the course itself, with
  optional semantic retrieval over pages, books, PDF, DOCX, PPTX, H5P and SCORM
  content and video transcripts.
- **Practice built in.** Practice quizzes, flashcards, worked examples, study
  plans with reminders, and essay feedback against a rubric. Practice only,
  never a Moodle grade.
- **Steps back during assessment.** While a learner has a quiz attempt open, the
  assistant is unavailable to them everywhere, including outside the course.
- **Support outside courses** (optional). On the dashboard and site pages it
  answers enrolment, certificate and technical questions from a support course
  and the FAQ, with its own three starters, and can hand off to Zendesk.
- **Readable answers.** Headings, lists, tables, quotes and code render in the
  chat, and an answer that runs out of room says so rather than stopping
  silently.
- **46 languages**, with automatic reply-in-your-language, speech input and
  output (OpenAI, xAI or, since 8.1.0, Gemini text to speech), and an optional
  live voice mode. Works on phones, including with
  Moodle's menu drawer open.
- **Any provider, one table of keys.** Gemini, OpenAI, Claude (including Opus
  5.5 and Sonnet 5.5), DeepSeek, Mistral, xAI, MiniMax, OpenRouter, Together,
  Ollama, Moodle's own AI subsystem, or any OpenAI-compatible endpoint. Every
  provider's key, models and base URL live in one **Providers and keys** table,
  so you can add or change a key without touching the default provider.
  Embedding, Rerank and Voice can use a row's key instead of a pasted copy.
  Failover, a premium tier for hard turns (Claude Sonnet 5, benchmark-backed),
  and spend caps per course.
- **Keeps up with new models.** It knows what each model accepts from data
  rather than name checks, fixes a rejected request by itself, and (unless an
  admin turns it off) tests newer models nightly and switches to one that's
  the same price or cheaper and at least as good, rolling back if live answers
  get worse. Voice models follow a catalog of shutdown dates and successors, so
  a retired voice model is never called, and admins are warned 45 days ahead.
- **Costs you can see.** A model registry with prices and their sources, a daily
  price-drift check, token analytics, cost anomaly alerts and benchmarks.
- **Safe defaults.** Nothing contacts a third party until an admin configures
  it: remote configuration, the Python sandbox runtime and the CDN delivery all
  default to off. The assistant opens by itself only on course pages, and only
  if an admin turns auto-open on.
- **Keys encrypted at rest, never shown, and replaced in one step.** Provider
  keys, the Voice providers table, webhook URLs and every other secret are
  stored with Moodle's own encryption, so a database backup alone doesn't
  reveal them. No settings page ever shows a key: a saved one reads "Saved, ends
  in ab12", and the settings-changed notice and Moodle's configuration log hide
  secrets too. A command lists where each key is stored (by its last four
  characters only) and replaces one key everywhere in a single transaction, and
  a Reports > Status check flags a key kept in several places.
- **White-label.** Four settings in Essentials > Branding rename the whole
  product, in every language: the widget and its tooltips, the prompts the
  model sees, alert and learner emails, default surveys and admin pages.
- **Instructor views.** Analytics, a review queue for learner feedback, Learning
  Radar, transcripts with pseudonyms, and surveys with validated rating scales.
- **Python sandbox** (per course). Runs in the learner's browser, never on the
  server, and shows the full error when code fails.
- **PresenterAI replaces Soapbox.** Soapbox has been hidden and switched off
  since 7.12.5; its data, playback and privacy handling stay until PresenterAI
  has imported it.

## Part 3: Admin Walkthrough Script: Gemini speech and retiring voice models (about 5 minutes, conversational)

Written to be read aloud while you click. It assumes a test site on 8.1.0 (the dev fleet), an admin login, a course with the assistant on, and a Gemini API key that may be used for testing. Don't use the production key.

### 1. Add a Gemini voice row (about 1 minute)

Open **Site administration, Plugins, Local plugins, AI Course Assistant**, then the Advanced page that holds **Voice providers**. Add a row: provider **Google Gemini**, the key, label `gemini-tts`, TTS voice `Kore`, and leave **TTS model** blank. Save.

"Blank means the default from the voice model catalog, gemini-3.8-flash-tts today. Gemini is text to speech only here, so the Realtime and speech-to-text dropdowns don't offer this row." Set **Text to speech provider** to `gemini-tts` and save.

### 2. Hear it (about 1 minute)

Open the course as a student, ask a question, and press the speaker button on the answer. "That audio came from Gemini as raw PCM. The server wraps it in a WAV header so the browser can play it." If it falls back to the browser voice, open the browser's network tab: tts.php answers with the provider's HTTP status, which is the place to start.

### 3. A model that is being retired (about 1 minute)

Edit the row and set **TTS model** to `gemini-2.5-flash-preview-tts`. Save and play an answer again. "Until 18 December 2026 that model is still called. From that date on, the catalog sends gemini-3.8-flash-tts instead, without anyone editing the row." Run the watch task from a shell:

```bash
sudo -u www-data php admin/cli/scheduled_task.php --execute='\local_ai_course_assistant\task\voice_model_watch'
```

"It names the model, the shutdown date and the successor, and emails the spend alert recipients once. Run it again and nothing new is sent."

### 4. A model the provider refuses (about 1 minute)

Set **TTS model** to a name that doesn't exist, such as `gemini-0-tts`, save, and play an answer. "Google answers that the model isn't found. tts.php retries once on the catalog default, writes a `voice_model_fallback` row in the audit log, and emails the spend alert recipients, once for that model." Open the audit log to show the row.

### 5. Put it back (about 30 seconds)

Clear **TTS model**, or remove the Gemini row and set the text to speech provider back to what it was. Save.
