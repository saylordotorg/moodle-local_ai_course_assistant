# SOLA v7.6.6: Release Notes

## Part 1: Release Notes (3 October 2026)

## v7.6.6 (3 October 2026): Claude Opus 5.5 works, and a benchmark says it should not be the premium tier

**Two requests made Claude Opus 5.5 unusable.** Both return HTTP 400 for the
whole request, and the streaming path swallows the error body, so each one
reached a learner as the generic "Sorry, something went wrong" with nothing in
the log naming the parameter.

The first was `temperature`. The check that decides whether a model accepts it
was already right, but turning thinking on set `temperature` to 1 before that
check ran, on the old rule that extended thinking needs exactly 1. That rule
only applies to models that still accept the parameter. Opus 4.7 onward removed
it, so every thinking call failed while the ordinary path worked, which looks
like an intermittent provider fault rather than a request built wrong.

The second was forcing a tool call. Opus 5.5, Sonnet 5.5, Fable 5.1 and Mythos
5.1 no longer accept a forced `tool_choice`, and structured output is the only
thing that uses one, so every structured-output call on those models failed. It
now lets the model choose with a strict schema and an instruction to use the
tool. The instruction goes in its own system block so the cached part of the
prompt stays identical from call to call.

**Opus 5.5 was billed 25% too high.** It costs less than Opus 5 ($4/$20 per
million tokens against $5/$25), but with no price of its own the cost table
matched it to Opus 5. The default Claude model also moves off a 2025 snapshot.

**The premium tier stays on Claude Sonnet 5, now measured twice.** The branch
briefly moved the premium escalation target to Opus 5.5. Before shipping, the
50-prompt golden tutor benchmark was re-run with Sonnet 5, Opus 5 and Opus 5.5
side by side, using the same prompts and judge as the August run:

| Model | Rubric (of 15) | Cents per call | Time to first token |
|---|---:|---:|---:|
| Claude Sonnet 5 | 14.46 | 0.411 | 650 ms |
| Claude Opus 5 | 14.38 | 2.290 | 5,158 ms |
| Claude Opus 5.5 | 14.00 | 1.395 | 2,299 ms |

Opus 5.5 came last, at 3.4 times the cost and 3.5 times the wait. The August
ranking of Sonnet 5 over Opus 5 reproduced, so the harness is stable. The whole
gap is Socratic guidance: accuracy and tone were essentially identical for all
three, but Opus 5.5 scored 3 or below on guidance on 14 of 50 prompts against
Sonnet 5's 4. It is not less accurate; it is quicker to hand over the answer,
which is the wrong habit for a tutor and the exact turns this tier exists for.
The target went back to Sonnet 5 before release.

## Part 3: Admin Walkthrough

Unchanged from v7.5.7, with one addition: after upgrading, check Site administration, Plugins, Local plugins, AI Course Assistant, and confirm "Remote config URL" is empty.
