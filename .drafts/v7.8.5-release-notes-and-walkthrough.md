# SOLA v7.8.5: Release Notes and Walkthrough

## Part 1: Release Notes (9 October 2026)

## v7.8.5 (9 October 2026): SOLA answers in the language you write in

**What changed.** SOLA now picks the language of each reply in this order: the language the question is written in, then the language saved in SOLA's language picker, then the browser's language. It answers in 46 languages.

**Asking before switching.** If a learner who saved a language writes in a different one, SOLA asks in chat, in the language they wrote in, whether to switch, with a button for each language named in its own script. The saved setting changes only if they agree. Typing "yes" or "no" works too, in any language. A refusal is remembered for the session. A learner who never chose a language is just answered in the language they write in. English-locked courses never ask.

**Smaller fixes.** The browser's language is no longer written into the saved setting on a first visit, because that made a guess look like a choice. A reloaded chat shows the two buttons again, and the question is no longer stored twice. Clicking the Chat tab again while already on Chat shows the usual starter chips together with the follow-up chips from the most recent reply.

## Part 2: Walkthrough (about 3 minutes)

1. In the SOLA settings panel, choose English as the language. Ask a question in Spanish.
2. SOLA asks, in Spanish, whether to switch, with a button for each language named in its own script. Choose the Spanish button: the question is answered in Spanish and the saved language changes. Repeat with the English button on another Spanish question: the saved language stays English and SOLA doesn't ask again this session.
3. Reload the page and reopen SOLA. The two buttons are back, and History shows the question once.
4. As a learner who never chose a language, ask in Spanish. SOLA just answers in Spanish and doesn't ask.
5. Open an English-locked course and ask in Spanish. SOLA never asks there.
