Version 7.6.9 (build 2026100110)

The plugin-directory review's template work is finished, and converting the
last two pages turned up two bugs they had been hiding.

The review named eight places that built pages by echoing HTML with inline
scripts, inline styles or an inline click handler. Six were converted earlier.
This release converts the last two, the Python sandbox page and the "reset to
template" button on the system prompt setting, and a test now covers all eight
so the pattern can't quietly come back.

The sandbox never showed a learner their actual Python error. When code failed,
the learner saw only the word "PythonError". The sandbox captures Python's error
output so it can display it, and that capture is also where the runtime puts the
error message, but the page read the message from somewhere else that was always
empty. Learners now see the full error, ending with the line that names what
went wrong. The sandbox also reports a missing or wrong runtime within a couple
of seconds instead of waiting 15.

"Reset to template" garbled the default prompt in 37 of the 46 languages. The
button restored the default system prompt using a browser function that doesn't
handle accented or non-Latin characters, so accented French came back as
mojibake. English uses only plain characters, so it was never noticed. The
default prompt now reaches the button exactly as written.

The Marketplace description is now checked automatically against the Moodle
versions the plugin declares, 4.5 through 5.2, so the listing can't again
promise a version the plugin doesn't claim.

Tested: 2,074 automated tests with no failures, the security validator corpus at
36 of 36, and PHP lint clean across 609 files. Seven of the new behaviors were
checked by deliberately reintroducing the bug and confirming the test failed,
and the sandbox and reset button were exercised in a real browser. Continuous
integration covers PHP 8.1 through 8.3 against Moodle 4.5, 5.0 and 5.1, on both
MariaDB and PostgreSQL.
