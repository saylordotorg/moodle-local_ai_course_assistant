# SOLA v7.8.1: Release Notes, Feature Summary, and Admin Walkthrough

## Part 1: Release Notes (8 October 2026)

## v7.8.1 (8 October 2026): Automatic follows the model, and failures and changes are visible

**"Automatic" now picks the provider that makes your model.** With the provider on Automatic and a key saved, SOLA used to choose OpenAI whatever the model was. A Gemini key with `gemini-2.5-flash` was sent to OpenAI, rejected, and every call was quietly answered by the backup model (GPT-4o-mini on our dev site, for about 22 hours). Automatic now reads the provider off the model name (claude-, gemini-, gpt- and the o-series) and uses it with your key. If the name says nothing, it still falls back to OpenAI as before.

**A status check tells you when the main provider is failing.** Under Site administration > Reports > Status, "AI Course Assistant main provider" reports the main provider's failures in the last 24 hours and how many turns the backup answered: a note under 3, a warning from 3, an error from 10. The last error is shown with anything credential-shaped removed.

**Every settings save lists what it changed.** After you save, a notice names each AI Course Assistant setting the save changed, old value to new. Credentials show as "changed (value hidden)", and a multi-line setting saved again with only different line endings is labelled as that. A provider, model, key, failover or support-mode change, or more than 8 changes at once, shows as a warning. The README now tells admins to use the individual settings pages: the all-settings page holds about 350 fields in one form and saves them together.

**Not found:** how the provider on dev became Automatic. The same save also turned off support mode. An unedited save of every settings page keeps the provider, and no code links the two settings, so we couldn't reproduce it. The save notice exists so the next one is visible straight away.

## Part 2: Key SOLA Features (snapshot)

- Tutor chat grounded in the course's own content, with Socratic guidance, quizzes, study plans, flashcards, voice mode and 46 languages.
- Any of 12 providers, with per-call failover, spend caps and emergency controls.
- Model capability profiles, self-healing requests and nightly automatic model upgrades (v7.8.0).
- Instructor analytics, Learning Radar and cost reporting.

## Part 3: Admin walkthrough (about 5 minutes)

1. Open Site administration > Plugins > Local plugins > AI Course Assistant > AI provider and models. Leave Provider on Automatic with a Gemini key and `gemini-2.5-flash`. Send a chat message as a test learner; Reports > Live logs or the message's provider column shows `gemini`.
2. Change one harmless setting and Save. Point out the notice listing it.
3. Open Reports > Status and find "AI Course Assistant main provider". It reads "No failures".
4. To see the warning, set a bad key in a test copy, send three messages, and reload the status page: the check names the model and the last error, and says how many turns the backup answered.
5. Close by saying where to change settings: the individual pages, not the all-settings page.
