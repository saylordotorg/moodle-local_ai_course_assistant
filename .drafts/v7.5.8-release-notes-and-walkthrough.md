# SOLA v7.5.8: Release Notes

## Part 1: Release Notes (28 September 2026)

**No functional change. A lang-file tidy, made before the plugin-directory submission.**

The v7.5.7 translation pass added a comment line, `// v7.5.7: support mode outside courses.`, to each of the 45 non-English locale files. Moodle's code checker flags each one twice: `moodle.Files.LangFilesOrdering.UnexpectedComment`, because comments in a lang file break its automatic ordering, and `moodle.Commenting.InlineComment.NotCapital`, because the line opens with a lowercase "v".

Ninety warnings, all of them avoidable, on a plugin whose open approval ticket is a code review. They are warnings rather than errors and nothing behaves differently because of them, which is exactly why they were easy to add without noticing.

The comment lines are removed. All six support-mode strings remain present in all 46 locales, verified per locale rather than in aggregate.

### What did not change

No PHP, no JavaScript, no templates, no capability, no schema. The version increases because Moodle needs a version change to pick up the modified language files.

Plugin version `2026092803`, release `7.5.8`.
