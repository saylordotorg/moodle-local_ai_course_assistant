Version 7.6.7 (build 2026100108)

On the newest Claude models, a quiz or an essay score could quietly fail to
come back. This release retries once when that happens, and bills both
attempts.

Claude Opus 5.5, Sonnet 5.5, Fable 5.1 and Mythos 5.1 no longer accept an
instruction that forces the model to call a tool, so the plugin now asks the
model to use the tool instead. Asking is not a guarantee. If the model answered
in plain text instead, the code waiting for structured data could not read it,
and quiz generation, essay or speech scoring, flashcards, learning objectives or
conversation classification failed for that request.

The plugin now tries once more in that case, which is what Anthropic recommends
for these models. It retries only for structured output, only on a model that
cannot be forced, and only when the reply is otherwise normal but contains no
tool call. Ordinary chat and older models are never retried.

Both attempts are billed. A simple retry would have recorded only the second
request's tokens, so every retried call would have been billed at roughly half
its real cost. The two attempts are now added together. If the retry is
refused, comes back empty or fails to connect, the plugin returns exactly what
the first attempt would have, so a retry never makes a request worse.

This release was also checked against the live API rather than only by
automated tests, which is how the previous release's problem slipped through.
The real learning objectives request went through the real provider code to
Claude Sonnet 5.5, Opus 5.5 and Sonnet 5, and all three returned between 11 and
12 objectives with token usage recorded.

Tested: 2,058 automated tests with no failures, the security validator corpus
at 36 of 36, and PHP lint clean across 600 files. Three of the new behaviours,
including the billing one, were checked by deliberately reintroducing the bug
and confirming the test failed. Continuous integration covers PHP 8.1 through
8.3 against Moodle 4.5, 5.0 and 5.1, on both MariaDB and PostgreSQL.
