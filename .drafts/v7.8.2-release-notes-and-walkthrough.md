# SOLA v7.8.2: Release Notes, Feature Summary, and Admin Walkthrough

## Part 1: Release Notes (8 October 2026)

## v7.8.2 (8 October 2026): balanced quiz answer keys, an essay model setting, and benchmark follow-ups

Every item comes from the 8 October LLM benchmark.

**Quiz answer keys are balanced.** Three of the four models tested never keyed D, one keyed A on 52 of 75 questions, and two made the correct answer the longest option on about 70% of questions, so a learner who always picked the longest choice scored 72%. Two fixes now run on every quiz, whatever the model:
- **Length:** where the correct answer is more than 20% longer than the longest wrong one (and by 6+ characters), SOLA asks the model once, for the whole quiz, to rewrite those questions' wrong choices to match its length. The correct answer is never shortened. If the rewrite fails or doesn't help, the original stays.
- **Letters:** every question's correct answer then moves to a random letter. Explanations that name a letter ("option B", "(C)", "A is correct") are rewritten to follow, and the prompt now asks models not to name letters at all.
The rewrite is one extra call per quiz (only when a question is flagged), logged as usage like any other.

**Essay feedback has its own model.** Two new settings, Essay feedback provider and model, route essay feedback separately; both must be set, otherwise it uses the chat model as before. In the benchmark the Claude models gave clearly better essay feedback than Gemini 2.5 Flash or GPT-4o mini.

**Claude 5.5 reasoning level.** The reasoning effort setting now reaches Claude Sonnet 5.5 and Opus 5.5 as `output_config.effort`; Off sends the lowest thinking setting on Sonnet 5.5 (Opus 5.5 can't turn thinking off, so Off means effort low). Thinking models get the same answer headroom as Gemini and OpenAI reasoning models. Other Claude models are sent exactly what they were. A site that runs Sonnet 5.5 with the default setting (Low) now sends effort low where it used to send nothing (the model's default is high).

**Smaller fixes.**
- Claude's thinking tokens are now recorded (cost is unchanged; they were already in output tokens).
- Registry prices: claude-haiku-5-5 ($0.10/$0.50, was estimated at 10x), gpt-oss-120b ($0.15/$0.60, had none), and OpenRouter Llama 3.1 8B corrected to $0.05/$0.08.
- Model discovery makes a one-token call before offering a candidate, so a model the provider lists but refuses (gemini-2.5-flash-lite answered 404) isn't proposed. Only a 404 rejects; timeouts, rate limits and key problems keep the candidate.
- The Max tokens and reasoning effort help texts now say what the limits are: with thinking on, a long answer can run to about three times Max tokens; with thinking off it's cut at exactly Max tokens.

## Part 2: Key SOLA Features (snapshot)

- Tutor chat grounded in the course's own content, Socratic guidance, quizzes, study plans, flashcards, voice mode, 46 languages.
- Any of 12 providers, per-call failover, spend caps, emergency controls.
- Capability profiles, self-healing requests and nightly automatic model upgrades (7.8.0); Auto follows the model, a failing-provider status check and a settings save notice (7.8.1).

## Part 3: Admin walkthrough (about 5 minutes)

1. Generate a quiz on a page, take it, and note the correct letters vary between questions.
2. Open Plugins > Local plugins > AI Course Assistant > the settings page with Quiz coach model; set Essay feedback provider and model (for example `claude` and `claude-haiku-4-5`) and save. The save notice lists what changed.
3. Submit an essay for feedback and look at the model on the usage row.
4. Open Reports > Status for the main-provider check, and the Model registry page for the new prices.
