# SOLA v7.8.3: Release Notes and Walkthrough

## Part 1: Release Notes (9 October 2026)

## v7.8.3 (9 October 2026): practice quiz wrong answers are cleaner

I measured v7.8.2 on 15 course pages and found two things still wrong, both reported in #309.

**Absolute words in wrong choices.** 53% of Claude Haiku 4.5's questions (20% on Sonnet 5.5) had an absolute word such as "all", "only", "exact" or "eliminate" in a wrong choice, which tells a learner it is wrong without knowing the subject. Any distractor containing one of about 35 such words is now rewritten, and a replacement that contains one is never accepted. After: 2% (Haiku) and 0% (Sonnet 5.5).

**The correct answer was still the longest.** 7.8.2 left it longest on 64% of Haiku questions and 50% of Sonnet 5.5's, because the hard cases (a 173-character answer against distractors of 114) were rejected. The rewrite now gets the answer's length as a target, a second request handles what is still too short, and the better attempt is kept. After: 29% (Haiku) and 37% (Sonnet 5.5); chance is 25%.

No wrong keys were added (1 and 0 judged wrong on 65 and 60 questions). The number judged ambiguous was 5 on Haiku (3 before), 0 on Sonnet 5.5 (1 before), within noise at this size, but the rewriter doesn't see the course page, so it is worth watching.

## Part 2: Admin walkthrough (about 3 minutes)

1. Generate and take a practice quiz on a page. Wrong choices read as plausible, hedged statements, and the correct letter varies.
2. Open the AI usage report and find the "(distractor rewrite)" rows next to the quiz rows: one or two extra short calls per quiz.
