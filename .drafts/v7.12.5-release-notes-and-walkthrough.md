# SOLA v7.12.5: Release Notes and Walkthrough

## Part 1: Release Notes (6 November 2026)

## v7.12.5 (6 November 2026): Soapbox is hidden, PresenterAI replaces it

This patch hides the old Soapbox speech tool everywhere in SOLA's interface. It adds no table, column or capability, and no upgrade step.

**Hidden.** The Soapbox admin settings are out of the settings tree (the stored values stay in the database). The Soapbox speech practice section is gone from the course settings page, and the Soapbox speech-practice toggle is gone from the site pedagogy tool list. The course navigation no longer shows the Soapbox link, the assignment manager link or any per-assignment link. The speech rubric tab is hidden on the rubric editor, and the Soapbox storage probe is gone from the backend self-test page. The advanced settings page is now titled "Avatars and legacy".

**Fully switched off.** Soapbox now refuses at the server too. `feature_flags::resolve('soapbox')` is false whatever `soapbox_enabled` or `soapbox_enabled_course_N` say, so `score_speech`, `soapbox_transcribe.php`, `soapbox_get_upload_url` (all kinds, including frames and decks), `soapbox_finalize_recording` and `soapbox_render_deck` all refuse. The only way back on is the hidden CLI-only config `soapbox_legacy_reenable` set to 1 (for example `php admin/cli/cfg.php --component=local_ai_course_assistant --name=soapbox_legacy_reenable --set=1`); there is no settings page for it. Playback, the cleanup task and the privacy provider do not use the flag and keep working.

**Old links.** The four old Soapbox pages (`soapbox.php`, `soapbox_assign.php`, `soapbox_assign_edit.php`, `soapbox_present.php`) still check login and capability first, then show "This tool has been replaced by the PresenterAI activity." with a button back to the course. Nothing else on those pages runs, so an old bookmark cannot change data. Old Soapbox URL activities placed on course pages open the same notice.

**Kept on purpose.** No table or data is dropped. The nightly `soapbox_cleanup` task still deletes recordings on schedule (it reads the stored retention setting, with its built-in default if none is stored). The privacy provider still exports and deletes Soapbox data, and the course-delete observer still drops media. The recording and scoring web services, the speech rubric (reachable by direct link) and the `soapbox_*` config values are untouched.

**Known limits.** Course-level Soapbox switches that were already on stay stored but have no effect. The Soapbox strings in the 45 translated language files are unused but left in place. The new notice is English only for now.

### Testing

Full plugin PHPUnit suite on MySQL (Moodle 4.5): 3236 tests, all pass.

Plugin version `2026110601`, release `7.12.5`.

## Part 2: Walkthrough (about 2 minutes (admin))

1. Upgrade from 7.12.4. There is no upgrade step; the plugin version changes only.
2. Open the plugin settings. The Soapbox section is gone from the advanced "Avatars and legacy" page.
3. Open a course's AI settings. The Soapbox speech practice row is gone.
4. Open a course as a learner or teacher. The course menu has no Soapbox links.
5. Open an old Soapbox link. You see the short notice and a Continue button that goes back to the course.
