WHAT CHANGED SINCE v7.6.1

v7.6.2 closed other defects we found ourselves while reviewing the work done for
your findings. Four of them were data the plugin held that the people it
belonged to could not reach:

- An email opt-out stores a learner's address, and the only thing that writes
  one is the unsubscribe link, which is followed by someone who is not logged
  in, so every real opt-out stored no owner. Both discovery methods and both
  erasure paths look the owner up by id, so the address survived a subject
  access request, survived an erasure request, and survived deletion of the
  account.
- Consent and self-download are recorded outside any course and carry the
  learner's IP address and browser. Every audit query keyed on the course, so
  course zero matched none of them.
- Clearing the remote configuration URL in the admin form left up to an hour of
  cached remote values in place, including the system prompt. The upgrade step
  purged that cache for exactly this reason; the form had no equivalent.
- A learner's thumbs-down left the instructor review queue once their
  conversation passed the history cap, because the cap trims messages and every
  consumer joined through the message.

v7.6.3 did the Templates and Output API work from #273 and #278 on five more
admin pages, about 1,900 lines. Reviewing it found six defects, two of which the
migration itself introduced and two of which were caught by Moodle's own
Mustache Lint, a step with no local equivalent.

v7.6.4 fixes two things worth your attention.

THE SETTINGS CATEGORY PAGE RETURNED HTTP 500 AT DEVELOPER DEBUG

That is how I assume a reviewer runs. Moodle serializes a settings page's entire
show and hide dependency map into a single js_call_amd argument and warns above
1,024 characters. Ours was 5,290. The settings are now split across eleven pages
and the worst is 878 characters, with a test failing at 950. Same limit as #277,
which you filed.

ONE LEARNER-FACING ISSUE FIXED

Outside a course the assistant offered a starter called AI Project Coach, whose
prompt reads "help with a project or assignment for this course" when there is
no course. Support mode now supplies its own three starters, translated into the
full locale set. The test for this asserted the bug.

5.1, on MariaDB and PostgreSQL, and includes Mustache Lint.
