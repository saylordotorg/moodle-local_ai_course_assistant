# SOLA v7.6.7: Release Notes

## Part 1: Release Notes (4 October 2026)

## v7.6.7 (4 October 2026): structured output retries a missed tool call, and bills both attempts

**On the newest Claude models, a quiz or an essay score could quietly fail to
come back.** Claude Opus 5.5, Sonnet 5.5, Fable 5.1 and Mythos 5.1 no longer
accept an instruction that forces the model to call a tool, so since v7.6.6 the
plugin asks the model to use the tool instead. Asking is not a guarantee. If the
model answered in plain text instead, the code waiting for structured data could
not read it, and quiz generation, essay or speech scoring, flashcards, learning
objectives or conversation classification failed for that request.

The plugin now tries once more when that happens, which is what Anthropic
recommends for these models. It retries only in that one case: structured
output, on a model that cannot be forced, with a normal reply that contains no
tool call. Ordinary chat and older models are never retried.

**Both attempts are billed.** The obvious version of a retry would have recorded
only the second request's token count, so every retried call would have been
billed at roughly half its real cost with nothing to show it. The two attempts'
tokens are now added together. If the retry itself is refused, comes back empty
or fails to connect, the plugin returns exactly what the first attempt would
have returned, so a retry can never make a request worse than no retry.

**Refused requests are billed now, which they never were.** The review of this
change found that a refused or empty retry was still charged by the API but
left out of the recorded usage. The same flaw sat one line earlier, older than
this release: a refusal on the first try returned before its usage was
recorded, so every refused request was missing from the bill. Usage is now
recorded for every reply the plugin receives, before it decides what to do with
it.

**Checked against the live API this time.** The v7.6.6 fix passed every
automated test and would still have failed in production, because the tests
built the request without ever sending it. This release sent the real learning
objectives request through the real provider code to Claude Sonnet 5.5, Opus 5.5
and Sonnet 5. All three returned between 11 and 12 objectives with token usage
recorded.

### Testing

- 2,060 tests, 0 failures, 7 skipped.
- Security validator corpus 36 of 36.
- PHP lint clean across 600 files.
- Five new behaviours proved against planted defects with `scripts/prove_test.py`, including all three billing ones.
- Live structured-output round trip on Sonnet 5.5, Opus 5.5 and Sonnet 5: all returned objectives with usage.

## Part 3: Admin Walkthrough

Unchanged from v7.5.7, with one addition: after upgrading, check Site administration, Plugins, Local plugins, AI Course Assistant, and confirm "Remote config URL" is empty. If your site had never set it, the upgrade has cleared it and remote configuration is now off. If you had set your own URL, it is untouched and still active.
