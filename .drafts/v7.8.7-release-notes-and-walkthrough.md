# SOLA v7.8.7: Release Notes and Walkthrough

## Part 1: Release Notes (10 October 2026)

## v7.8.7 (10 October 2026): the language question is asked more reliably

When a learner has saved a SOLA language and writes in a different one, SOLA is meant to ask in chat whether to switch. On the lighter model Gemini 3.1 Flash-Lite it almost never did: in testing it asked on none of six tries and just answered. The rule now sits at the very end of the instructions SOLA reads, where the model follows it, and it states that English counts as a language like any other. With that change Flash-Lite asked on every Spanish and German test question, and it did not ask on questions already in the saved language, short replies like "ok thanks", or "how do you say..." questions. Claude Sonnet 5.5 asked correctly every time.

**Known limit.** On Flash-Lite, an English question from a learner whose saved language is not English is still answered in the saved language without asking. Stronger models ask correctly.

Plugin version `2026100905`, release `7.8.7`.

## Part 2: Walkthrough (about 2 minutes)

1. Set the chat model to Gemini 3.1 Flash-Lite and the saved SOLA language to English.
2. Ask a question in Spanish, then one in German. SOLA asks in chat whether to switch (in testing it asked every time; before 7.8.7 it asked on none of six tries).
3. Ask an English question and a short reply such as "ok thanks". SOLA just answers and doesn't ask.
4. Known limit: with a non-English saved language, an English question on Flash-Lite is still answered in the saved language without asking. Stronger models ask correctly.
