# SOLA v7.8.6: Release Notes and Walkthrough

## Part 1: Release Notes (9 October 2026)

## v7.8.6 (9 October 2026): the starter chips come back when you switch to Chat

In v7.8.5 the usual starter chips and the latest follow-up chips came back only if a learner clicked the Chat tab while already on Chat. Switching to Chat from Voice, History or Progress left the chip area empty. Found in a browser smoke test on dev. Both sets of chips now return on any switch to Chat.

Plugin version `2026100904`, release `7.8.6`.

## Part 2: Walkthrough (about 1 minute)

1. Open SOLA and ask a question. Wait for the follow-up chips.
2. Switch to Voice, History or Progress, then back to Chat.
3. The usual starter chips show together with the follow-up chips from the last reply. Before 7.8.6 the chip area stayed empty after a switch from another tab.
