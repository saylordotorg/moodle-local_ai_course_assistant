# SOLA v7.12.4: Release Notes and Walkthrough

## Part 1: Release Notes (30 October 2026)

## v7.12.4 (30 October 2026): the prompt-truncation warning appears only when cuts are frequent, and stops telling you to raise a number that would make things worse

This patch changes one admin-page notice. It adds no setting, table, column, capability or upgrade step.

**The warning needs a pattern.** The system prompt settings page warned for 7 days after a single turn lost retrieved course content. On Learn that was 1 turn in 5,129. It now appears only when course content was cut on more than 2% of the last 7 days' turns, with at least 20 turns recorded. Learn (0.02%) and Degrees (0.9%) would not have shown it.

**The advice matches the mode.** With "Derive from the model" selected, the number left at its 36,000 default and a known model window, the window decides the budget (up to 120,000 characters). Typing any other number makes it a fixed limit and replaces the window, so the old "raise the budget" advice could shrink the budget for large turns. The notice now says not to type a number in that case and suggests retrieving less per question, or setting the mode to Fixed and choosing a larger number on purpose. With a typed number, Fixed mode, or no known window, the original "raise it" text is kept, because there raising the number is the right fix.

**Known limits.** The 2% and 20-turn thresholds are fixed, not settings. The new string is English only for now. The warning still depends on the Prompt metrics log, so a site that turns `prompt_metrics_enabled` off never sees it.

### Testing

- New `prompt_truncation_warning_test` (11 tests). `settings_layout_test`, `settings_usage_test`, `lang_completeness_test`, the i18n drift and placeholder tests, `settings_page_structure_test` and `prompt_budget_ceiling_test` pass on MySQL. Two existing tests now seed turns with frequent cuts, because the notice is no longer built from the timestamp alone.

## Part 2: Walkthrough (about 2 minutes (admin))

Nothing a learner sees changes.

1. Upgrade from 7.12.3. There is no upgrade step; the plugin version changes only.
2. Open the Prompt metrics page and note "Turns where any section was truncated". Open the system prompt settings and confirm no truncation warning shows when course content was cut on 2% of turns or fewer.
3. To see the notice, a site needs a cut within the last 7 days on more than 2% of at least 20 turns.
