# v7.4.0 model registry — wiring manifest

Spec lines for the later stage that owns `settings.php` and `lang/`. Wave-1 (schema +
`classes/model_registry.php` + `token_cost_manager` + `rate_card_refresher`) touched
neither, per the hard constraint.

No new admin **setting** is strictly required for wave 1 to function: pricing lives in
the `local_ai_course_assistant_models` table and pricing sources live in
`local_ai_course_assistant_pricesrc`, both reached by forms the later waves build. The
items below are the surfaces wave 1 created that need a string or a settings-page link.

## Config keys written by wave 1 (no settings.php declaration needed)

- `rate_card_last_refresh_skipped` — integer, written by
  `rate_card_refresher::refresh()`. Count of upstream rows the refusal rule declined to
  apply because the stored row's `source` is `manual`. A run that skips rows is a
  SUCCESS; this is the only place that fact is visible. Existing siblings
  (`rate_card_last_refresh_at` / `_status` / `_error`) are written the same way and are
  likewise not declared as settings.

## Lang strings

- `settings:rate_card_refresh_success` — EXISTS; its `{$a}` is now "rows written"
  (inserted + updated) rather than "entries in the blob". Same meaning to an admin, no
  change needed, but if the copy is revisited: consider a second placeholder for the
  skipped count, e.g. `{$a->written} price(s) updated, {$a->skipped} left alone because
  an admin had corrected them`.
- `registry:heading` — "Model registry" (admin page title, wave 2).
- `registry:layer_baseline` / `registry:layer_legacy_overrides` / `registry:layer_table`
  / `registry:layer_none` — human labels for the four values
  `model_registry::provenance_for()` returns in its `layer` key. `none` is the
  load-bearing one: it means "this model bills as $0.00".
- `registry:source_manual` / `_upstream` / `_drift` / `_bundle` — labels for the
  `source` column.
- `registry:unpriced_warning` — banner text for `model_registry::unpriced_models()`
  returning non-empty, e.g. `{$a} model(s) in use have no price and are billing as
  $0.00`.
- `registry:skipped_manual` — inline note where a feed declined to overwrite a human's
  correction.

## Settings-page link

  "Refresh rate card now" control (`rate_card_refresh.php`), since the two now write the
  same table.
